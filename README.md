# 漫画摩托 · 公路乱斗

[在线游玩](https://wentaopeng714-cmd.github.io/comic-moto/)

版本 1.4.1：八关生涯、七名对手、四车道道路、不同场景与路面、警察追击、车辆与升级，以及连续赛道朝向修复。

电脑：A / D 或方向键转向，J / K 左右攻击，空格加速，S 刹车，L 恢复。也支持屏幕触控按钮。首次点击后启动声音，建议横屏游玩。

进度保存在当前浏览器的站点存储中。GitHub Pages 和本机预览是不同站点，进度各自保存。

## 本地运行

在目录中运行 `python3 -m http.server 8774 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8774/`。

静态网页部署，无服务器 API 或账户系统。美术使用生成的漫画风素材，音乐和音效通过 Web Audio 合成。
